第二层闸门 · 接口 + 参数 + 参数值（自动降级）

灰度系统按「接口 + 参数 + 参数值」三维度指定灰度范围（能力已具备）。三步逐步扩大已放量范围；不符合条件的入参自动降级、不进入灰度。

参数 第一步放量（L1 值） 第二/三步放量（L2 值） 全程降级（L3/L4 值）

authConfig.willingnessAuthModes CODE_SMS · SIGN_PWD PSN_FACE_* · PSN_MOBILE_FACE_AUTH PSN_AUDIO_VIDEO_*
signers[].signerType 0 · 1 · 3 2（法定代表人） —
signFields[].signFieldType 0（签章区）· 2（日期） 1（备注签字区） —
normalSignFieldConfig.autoSign false（默认） true（第二步 · 66.65% 流量） —

注：后置接口（revoke / urge / delay / 列表 / 签署区 / 文件 / 附件 / 抄送方）按 signFlowId 归属路由，不参与自动降级；不适配时按 gid 人工黑名单处理。

三步放量 —— gid 范围与参数 / 参数值范围逐步扩大
STEP 1

STEP 2
小客户 + 自动签
500+ appid 日均签署流程 ≥ 5000

appid：在第一步基础上，扩大一部分小客户 appid

专项：验证自动落章、印章授权、静默签授权联动
进入第三步门槛：appid ≥ 500 · 签署流程日均 ≥ 5000
STEP 3
按比例逐步放开

进阶门槛
依据《F-004 灰度放量方案》绘制 · 两道闸门：gid 维度（套 appid，同进同出）→ 接口 + 参数 + 参数值（范围外自动降级）。三步逐步扩大 gid 放量范围和参数/参数值范围：第一步小客户 L1+L2 且 autoSign≠true，第二步扩大小客户并开放 autoSign=true，第三步按比例逐步放开并保留大客户黑名单，最终覆盖基于文件发起流量 85%。
