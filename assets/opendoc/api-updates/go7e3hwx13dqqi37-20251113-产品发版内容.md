+ **<font style="background-color:#EFF0F0;">psnSealStyles</font>** 新增枚举值： 3 - 图片签名（由用户自主上传本地图片进行签署，仅限signMode：GLOBAL - 海外签时支持指定）

### 2、发起签署接口增加外国人永久居住证类型
🚩[**《基于文件发起签署》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/su5g42)**、**[**《通过页面发起签署》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/lp54bn)**接口新增请求参数枚举值：**

+ **<font style="background-color:#EFF0F0;">psnIDCardType</font>**** **新增枚举值： CRED_PSN_CH_GREEN_CARD - 外国人永久居住证（15位或18位）

![](https://cdn.nlark.com/yuque/0/2025/png/447795/1763114611473-d88cd396-7ae3-430d-a407-7f093dec85f5.png)

### 3、发起签署接口支持不可编辑个人实名手机号
🚩[**《基于文件发起签署》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/su5g42)**、**[**《通过页面发起签署》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/lp54bn)**接口新增请求参数枚举值：**

+ **<font style="background-color:#EFF0F0;">uneditableFields</font>**** **新增枚举值： psnMobile - 个人实名手机号

![](https://cdn.nlark.com/yuque/0/2025/png/447795/1763114743128-c51f3054-6dcb-4a37-aa94-e1b7c6a0ce27.png)



### 4、下载已签署文件接口增加下载链接有效期
🚩[**《下载已签署文件及附属材料》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/kczf8g)**接口新增请求参数：**

+ 新增请求参数 **<font style="background-color:#EFF0F0;">urlAvailableDate</font>**** **：下载链接有效期，单位：秒。默认：3600秒（60分钟）

![](https://cdn.nlark.com/yuque/0/2025/png/447795/1763115164266-c5bc1e62-30c4-41d3-b5c1-2b081cb21e30.png)

### 6、模板中的单行文本支持设置填写格式规则
🚩[**《获取制作合同模板页面》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/xagpot)**获取的模版样式新增功能：**

支持单行文本设置填写格式规则，允许添加的规则包含：

+ 仅大写字母；
+ 仅小写字母；
+ 仅字母和数字；
