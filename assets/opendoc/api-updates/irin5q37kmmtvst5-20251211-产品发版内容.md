### 1、<font style="color:rgb(38, 38, 38);">下载签署后文件增加POST请求及加密参数</font>
🚩[**《下载已签署文件及附属材料》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/kczf8g)**接口新增POST请求方式：**

![](https://cdn.nlark.com/yuque/0/2025/png/447795/1765525700520-7929de73-cd9e-4d17-825f-7d4cc30d4bf9.png)

🚩[**《下载已签署文件及附属材料》**](https://qianxiaoxia.yuque.com/opendoc/pdf-sign3/kczf8g)**接口新增请求参数：**

+ 新增请求参数** ****<font style="background-color:#EFF0F0;">rsaSecret</font>**： 文件需要加密时使用的RSA公钥（base64编码）
+ 新增请求参数** ****<font style="background-color:#EFF0F0;">rsaSecretKey</font>****： **RSA公钥版本（开发者自定义唯一标识，可用该字段标识对应的rsaSecret加密版本）
+ 新增请求参数** ****<font style="background-color:#EFF0F0;">internalUrl</font>****：**是否是内网地址，默认：false

![](https://cdn.nlark.com/yuque/0/2025/png/447795/1765525877219-7cb713ce-7ef3-46f5-a1ea-d8b021db6f41.png)
