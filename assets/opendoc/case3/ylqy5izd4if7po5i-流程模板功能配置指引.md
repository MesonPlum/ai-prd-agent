# 填写/签署顺序
## 基础介绍
模板支持设定多方填写和签署顺序。支持自定义调整填写/签署顺序。各参与方将按您设定的顺序依次填写/签署。

例如：A和B签署合同，指定的A先签署B后签署，A签署完成后B才能进行签署。

<font style="color:#DF2A3F;">注意：填写顺序不可以设置无序。</font>

## 效果展示
![](https://cdn.nlark.com/yuque/0/2025/png/447795/1764057747614-b75dc861-03f0-45aa-8aa9-1e984b277f14.png)   ![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1756712633868-98e3f86b-0557-4474-b8a0-6bce2f94121a.png)

## 设置教程
进入模板编辑页面，“顺序设置”可以开启和调整填写/签署顺序。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1756203752103-98e58105-4735-441c-b891-078540ca9a0b.png)

填写顺序：填写顺序不可设置为无序，拖动可调整顺序。  
签署顺序：需开启后才可以设置签署顺序，不开启表示无序签署。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1756204345104-476f4416-acf0-4d84-a12a-84209c05f97d.png)

# 签订截止日期
## 基础介绍
当发起合同签署时，用户默认有90天的签署有效期，如需要指定小于90天的截止签署日期，需要额外通过参数接口控制（**<font style="color:#DF2A3F;">注：在模板中设置的截止时间不生效</font>**）。当用户在指定时间内未签后签署任务将过期作废，需要重新发起。

## 效果展示
![](https://cdn.nlark.com/yuque/0/2025/png/447795/1764058195073-edd7ed63-faeb-4d58-b8e7-da9e730eb01f.png)![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758536588422-7ee685d9-dc08-49bc-b677-498076f378ca.png)



## 接口参数设置
需使用【[通过流程模板创建合同拟定和签署流程](https://open.esign.cn/doc/opendoc/file-and-template3/megwsgkmpbg1tec1)】接口，signFlowExpireTime参数设置签署截止时间（毫秒级时间戳）。**<font style="color:#DF2A3F;">注：在模板中设置的截止时间不生效</font>**。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758536937683-ca0fb328-ff34-443c-8401-3db25a6ba7a2.png)

```json
"signFlowConfig": {
  "signFlowExpireTime":1673314730000
}
```

# 显示签署日期
## 基础介绍
> 当使用模板发起合同签署时，用户在签章/签字的同时，会显示签署的日期，签署完成后会自动添加实际的签署完成时间到合同中。
>

## 显示效果
![](https://cdn.nlark.com/yuque/0/2025/png/447795/1764058431003-a0bb2e4e-8e21-4abb-b909-59f0b7dc8fce.png)![](https://cdn.nlark.com/yuque/0/2022/png/447795/1668061134621-50e7d372-4229-406a-b404-099252dc738b.png)



## 设置教程
**方式一**：选中签署区，在签署区属性面板中开启显示签署日期，默认在显示在签署区下面，不支持调整签署日期位置（**<font style="color:#DF2A3F;">骑缝章不支持添加签署日期</font>**）。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758709108921-a4f2b397-5568-4558-bf66-30793fa7605b.png)

**方式二**：使用单独的签署日期控件，支持拖动调整位置。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758708635655-c5942bbb-923f-4331-a958-6fecf55a85c3.png)

# 平台方自动落章
## 基础介绍
> <font style="color:rgb(15, 17, 21);">通过流程模板发起签署任务，系统可无缝调用预先授权给该模板的电子印章，实现平台方印章的自动签署，有效提升批量合同处理效率与规范性。</font>
>

## <font style="color:rgb(15, 17, 21);">模板设置</font>
在设置文件与参与方页面-设置参与方，选择“固定成员”，企业信息填写为：平台方企业名称（appid所属企业）和管理员手机号和管理员姓名。

![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758701833754-046ec2e1-ff09-4c96-94c1-2a370adcf29b.png)

## 印章授权设置
印章授权模板自动落章，有如下两种方式设置（<font style="color:#DF2A3F;">印章授权只需要设置一次，模板修改后需要重新设置</font>）。

+ <font style="background-color:rgb(253, 253, 254);">方式一：</font>[<font style="background-color:rgb(253, 253, 254);">接口发起印章内部授权（点击查看）</font>](https://open.esign.cn/doc/opendoc/helper/si1ih3va3oilpd24#lSDBP)<font style="background-color:rgb(253, 253, 254);">（</font>**<font style="color:#DF2A3F;background-color:rgb(253, 253, 254);">需专业版</font>**<font style="background-color:rgb(253, 253, 254);">）</font>**<font style="background-color:rgb(253, 253, 254);">--> </font>**[<font style="background-color:rgb(253, 253, 254);">点击跳转 接口在线调试</font>](http://118.178.195.80:88/#InternalAuth)
+ <font style="background-color:rgb(253, 253, 254);">方式二：</font>[<font style="background-color:rgb(253, 253, 254);">官网进入印章管理里授权（点击查看）</font>](https://open.esign.cn/doc/opendoc/helper/si1ih3va3oilpd24#lRH7D)<font style="background-color:rgb(253, 253, 254);">（</font>**<font style="color:#DF2A3F;background-color:rgb(253, 253, 254);">需高级版</font>**<font style="background-color:rgb(253, 253, 254);">） </font>

当开发者开启拟定流程后，当前流转到的用户在页面填写的已填写或拒填状态，会通过【[流程填写人填写状态通知](https://open.esign.cn/doc/opendoc/notify3/wg4lh0m89cyg4a6y)】给开发者components参数为用填充控件信息。![](https://cdn.nlark.com/yuque/0/2025/png/22781961/1758710148817-fab7cb92-097c-47dc-aba7-231c3e5791b7.png)
