## 架构定位

APPID 配置层是 e签宝 OpenAPI 的**租户级控制面**，介于平台运营管理和 API 服务执行之间。每个 APPID 绑定一套配置，所有在该 APPID 下发起的 API 调用，其行为均受此配置约束。

```
┌─────────────────────────────────────────────────────┐
│  运营支持后台（平台侧）                               │
│  · 为每个 APPID 新增/修改配置值                      │
│  · 控制每个配置项是否在开放平台对开发者可见            │
└──────────────────────┬──────────────────────────────┘
                       │ 可见性 = true 时向下透出
┌──────────────────────▼──────────────────────────────┐
│  开放平台（开发者侧）                                 │
│  · 开发者可自行查看/修改「可见」的配置项              │
│  · 不可见项由运营代管，开发者无感                     │
└──────────────────────┬──────────────────────────────┘
                       │ 配置作用于每次 API 调用
┌──────────────────────▼──────────────────────────────┐
│  API 服务层（运行时）                                 │
│  两种优先级模式（取决于具体配置项）：                  │
│  ① 默认值模式：APPID 配置 = 默认值，                 │
│     API 调用传参可覆盖                               │
│  ② 约束范围模式：APPID 配置 = 允许范围，             │
│     API 调用传参只能在范围内选择，超范围报错/降级      │
│  （绝大多数配置项为①，少数关键配置为②）              │
└─────────────────────────────────────────────────────┘
```

## 配置分类速查

| 配置类型 | 典型配置项 | 覆盖业务域 | 优先级模式 |
|---------|-----------|-----------|----------|
| 认证方式配置 | `PersonRealname`（个人实名方式）、`OrganRealname`（企业实名方式）、`propOpenWillingness`（意愿认证方式） | auth3 | ② 约束范围 |
| 签署行为配置 | `propRealNameCert`（强制实名）、`propAutoPreserve`（归档存证）、`propOpenBillingPolicy`（扣费策略） | pdf-sign3 | ① 默认值居多 |
| 页面样式配置 | `Logo`、`Color`、`FootBanner`、`propOpenLogo`、`propOpenColor` | auth3 / pdf-sign3 / 模板服务 | ① 默认值 |
| 回调与地址配置 | `notifyUrl`、重定向地址、自定义域名前缀 | 通用 | ① 默认值 |
| 限流与时效配置 | `rateLimitInterval`、`rateLimitThreshold`、各认证次数上限 | 通用 | ② 约束范围 |
| 存证配置 | `evidenceType`、`propAutoPreserve`、`signNotaryDocType` | 数据存证 | ① 默认值 |
| 计费配置 | `propSaleScheme`（售卖方案）、`chargeForPreserve`（存证单独计费） | 计费 | ② 约束范围 |

## PRD 引用规范

写 PRD 时，凡涉及「行为由 APPID 配置决定」的场景，按以下方式标注：

```markdown
> **APPID 配置约束**：本功能行为受 APPID 配置项 `[code]`（[名称]）控制。
> 默认值：[defaultValue]。优先级模式：[① 默认值可覆盖 / ② 约束范围]。
> 详见：context/appid-config-model.md
```

示例：

> **APPID 配置约束**：可用的个人实名认证方式受 APPID 配置项 `PersonRealname` 控制。
> 默认值：`1,2,3,4,6`（人脸识别/银行四要素/支付宝人脸/腾讯云人脸/运营商三要素）。
> 优先级模式：② 约束范围——接口传参只能在 APPID 已开放的方式中选择。
