# 业务术语表

> **维护规则**：
> - 每次 `/requirement-clarifier` 保存 RDD 后,AI 识别新引入术语并提议追加,用户确认后写入
> - PRD §4「需求对象与概念模型」只写本需求新引入的术语,已有术语引用本文件,不重复定义
> - 术语定义须精确,边界约束须明确,避免歧义
> - `类型` 取值:`产品概念`(核心业务抽象)/ `枚举值`(固定取值集合)/ `UI文案`(界面标签,无独立业务语义)/ `系统字段`(技术字段)

## 关键业务流程

| 名词 | 类型 | 定义 | 约束/备注 | 首次引入 PRD |
|---|---|---|---|---|
| 实名认证 | 产品概念 | 验证用户真实身份的过程 | 方式:运营商三要素 / 银行四要素 / 人脸识别 | E-001 |
| 意愿认证 | 产品概念 | 确认用户签署意愿的过程 | 方式:人脸识别或短信验证码 | E-001 |
| 认证授权流程 | 产品概念 | 用户完成实名认证并授予应用访问资源权限的完整流程 | 标识符 authFlowId,有效期 30 天 | E-001 |
| 授权范围 | 产品概念 | appId 对用户资源的具体操作权限集合 | 字段名 authorizedScopes;常见值:get_org_identity_info / org_initiate_sign / manage_org_seal 等 | E-001 |
| 用印审批 | 产品概念 | 印章使用前的审批流程 | 流程内含审批人(SEAL_EXAMINER)和用印人(SEAL_USER)两种角色 | E-001 |
| 自动落章 | 产品概念 | 印章授权时可配置的自动盖章开关；开启后当签署区满足条件（授权全体成员 + 指定具体模板编号）时，系统自动完成盖章，无需人工操作 | 字段名 autoSign（boolean，默认 false）；与流程级 autoFinish 不同，属印章维度行为控制；仅 InternalSealAuth 接口支持 | seal-api Phase 2 |
| 自定义业务编号 | 系统字段 | 开发者在发起印章授权（内部/外部）时传入的业务侧关联编号，用于对账或业务追踪 | 字段名 customBizNum（string）；格式由集成方自定义，e签宝侧不校验；内部/外部授权接口均支持 | seal-api Phase 2 |
| 催签 | 产品概念 | 提醒待签方尽快完成签署的动作 | 通过 pdf-sign3/yws940 接口触发 | E-001 |
| 流程延期 | 产品概念 | 延长签署截止时间的动作 | — | E-001 |
| 流程完结 | 产品概念 | 所有签署任务完成后,正式关闭流程并触发文件归档 | 可通过 autoFinish=true 自动完结,或主动调用结束接口 | E-001 |
| 签署流程状态 | 枚举值 | 草稿 / 进行中 / 已完成 / 已撤销 | 字段名 status | E-001 |
| signFlowStatus | 枚举值 | 签署流程精细状态 | 0=草稿 / 1=签署中 / 2=已完成 / 3=撤销 / 5=过期 / 7=拒签 | F-003 |
| signerType | 枚举值 | 签署方类型 | 0=个人签署方 / 1=机构签署方 | F-003 |
| signOrder | int32 | 签署顺序 | 1-255，值小的先签署 | F-003 |
| signFlowExpireTime | int64 | 签署截止时间 | Unix 时间戳（毫秒），默认创建后 90 天 | F-003 |
| autoStart | boolean | 自动开启 | true=自动进入签署中 / false=需调用开启接口 | F-003 |
| autoFinish | boolean | 自动完结 | true=所有签署完成后自动完结 / false=需调用完结接口 | F-003 |
| signSceneType | 枚举值 | 签署场景类型 | NORMAL=中国大陆签 / GLOBAL=海外签 | F-003 |
| 套餐 | 产品概念 | API 调用量订阅计划,含余量管理 | 通过 order3 域管理 | E-001 |

## 参与方角色

> 业务流程中的角色定义。与平台权限模型(ABAC)无关,仅描述"在某个流程里谁负责哪一步"。
> 平台访问控制规则见 [permission-model.md](permission-model.md)。

| 名词 | 类型 | 定义 | 约束/备注 | 首次引入 PRD |
|---|---|---|---|---|
| 发起方 | 产品概念 | 签署流程的创建发起者 | 通常是集成方业务系统中的某个企业员工 | E-001 |
| 签署方 | 产品概念 | 在签署流程中需要完成签署任务的参与方 | 含签署人和填表补充人两个子角色 | E-001 |
| 签署人 | 产品概念 | 在指定位置完成电子签名的人 | 签署方子角色 | E-001 |
| 填表补充人 | 产品概念 | 在文件中填写指定字段(姓名/金额/日期等)的人 | 签署方子角色 | E-001 |
| 抄送方 | 产品概念 | 签署完成后收到通知的旁观方,无需操作 | 通过短信/邮件接收最终文件 | E-001 |
| 经办人 | 产品概念 | 企业签署流程中代表企业完成签署的人 | 可通过签署区调整或页面转交切换(TRANSMISS_SIGN 回调) | E-001 |
| 用印审批人 | 产品概念 | 审批是否允许用印的角色 | 英文标识符 SEAL_EXAMINER;用印审批流内角色 | E-001 |
| 用印人 | 产品概念 | 发起用印申请、需被审批的角色 | 英文标识符 SEAL_USER;用印审批流内角色 | E-001 |
| 生态伙伴 | 产品概念 | 经授权的分销商/集成商 | — | E-001 |

| componentGroupId | 系统字段 | 控件组唯一标识 | 归属 appId(非 fileTemplateId 或 signTemplateId) | E-001 |

| OAuthToken | 产品概念 | OAuth 鉴权令牌(鉴权方式之一) | V3 接口支持的鉴权方式;另一种是签名鉴权 | E-001 |
| 签名鉴权 | 产品概念 | V3 接口推荐的鉴权方式,基于 appId 私钥签名 | — | E-001 |
| V3 API | 产品概念 | e签宝 OpenAPI 第三代规范,统一参数定义和命名 | 路径含 `/v3/`;appId ≠ 7488 时校验 authorizedScopes | E-001 |
| 回调 Action | 产品概念 | Webhook 事件类型,标识具体回调场景 | 取值见下方枚举值 | E-001 |
