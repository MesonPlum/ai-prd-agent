## 核心定位

**产品名称**：e签宝 OpenAPI

**一句话价值主张**：为企业开发者提供合规的云端电子签名能力，通过 RESTful API 将电子合同签署服务集成到第三方系统（OA、HRM、CRM 等）。

**服务模式**：SaaS 公有云 API（主）+ 可选私有部署

**商业版本**：体验版 / 基础版 / 专业版 / 高级版 / 旗舰版；专业版及以上方可调用 API，高级版及以上可额外调用 5 个专属接口。详见 `context/product-editions.md`。

**产品边界约束**：本工作区仅服务 **OpenAPI 场景**，不覆盖 e签宝 完整 SaaS 产品（Web 控制台 UI、C 端 App 等）。

## 核心能力架构概览

| 模块 | 标识 | 职责描述 |
|------|------|----------|
| 认证授权 | auth3 | 实名认证三要素/银行四要素/人脸识别；意愿认证；用户授权（authFlowId） |

## APPID 配置层

每个 APPID 绑定一套租户级配置，所有在该 APPID 下的 API 调用行为均受其约束。共 457 个配置项，覆盖认证方式、签署行为、页面样式、计费策略、回调地址、限流阈值等维度。

**三层管理结构**：

```
运营支持后台 → 为每个 APPID 设置配置值，控制各项是否对开发者可见
      ↓（可见项透出）
开放平台     → 开发者可自助查看/修改「可见」的配置项
      ↓（配置作用于运行时）
API 服务层   → 按配置约束执行 API 调用
```

**两种优先级模式**：

| 模式 | 说明 | 典型场景 |
|------|------|---------|
| ① 默认值模式 | APPID 配置为默认值，API 调用传参可覆盖 | 页面样式、回调地址、签署行为 |
| ② 约束范围模式 | APPID 配置为允许范围，API 参数只能在范围内选择 | 认证方式列表、限流阈值、计费方案 |

> 详细配置分类与 PRD 引用规范见：`context/appid-config-model.md`  
> 完整 457 条配置项数据见：`assets/appid-config.md`

## 关键术语对照

| 术语 | 说明 |
|------|------|
| psnId | 个人用户账号 ID，对应手机号/邮箱登录凭证 |
| orgId | 企业/机构账号 ID，对应企业名称 |
| signFlowId | 签署流程唯一标识，每次发起签署生成 |
| authFlowId | 认证授权流程标识，有效期 30 天 |
| 实名认证 | 验证用户真实身份：运营商三要素/银行四要素/人脸识别 |
| 意愿认证 | 确认签署意愿：人脸识别或短信验证码 |
| 签署流程 | 一次合同签署的完整生命周期，从发起到完结 |
| 流程模板 | 企业侧预配置的签署流程，含起草方、签署方、顺序、抄送、控件 |
| 文件模板 | 开发者侧 PDF/HTML 合同模板，填充控件后生成签署文件 |
| 控件 | 签署区域/业务控件/自定义控件，嵌入模板或流程中 |
| 发起方 | 签署流程的创建发起者 |
| 抄送方 | 签署完成后收到通知的旁观方（短信/邮件） |
| 用印审批 | 印章使用前的审批流程，角色：SEAL_EXAMINER（审批人）/ SEAL_USER（用印人） |
| 套餐 | API 调用量订阅计划，包含余量管理 |
| 生态伙伴 | 经授权的分销商/集成商 |
| notifyUrl | Webhook 回调地址，接收签署状态/审批等事件推送 |
| authorizedScopes | 授权范围，如 get_org_identity_info / org_initiate_sign / manage_org_seal |
