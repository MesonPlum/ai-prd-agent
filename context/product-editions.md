# 产品商业版本与接口权限

> **维护规则**：
> - 版本新增/调整、接口权限变化时在此更新
> - 写 PRD §9「运营与商业约束」或涉及接口可用性时引用此文件
> - 接口权限列表如有变化，同步更新下方「版本专属接口」表

---

## 版本层级

| 版本 | 可调用 API | 备注 |
|------|-----------|------|
| 体验版 | ❌ 不可调用 API | — |
| 基础版 | ❌ 不可调用 API | — |
| 专业版 | ✅ 标准 API 全集 | 最低可用 API 的版本 |
| 高级版 | ✅ 标准 API 全集 + 高级专属接口 | — |
| 旗舰版 | ✅ 标准 API 全集 + 高级专属接口 | — |

---

## 高级版及以上专属接口（5 个）

> 仅 **高级版** 和 **旗舰版** 客户可调用，专业版及以下调用时应返回权限不足错误。

| 接口路径 | 说明 |
|---------|------|
| `GET /v3/collect-form/submitted-data-list` | 收集表单提交数据列表 |
| `GET /v3/collect-form/submitted-data` | 收集表单提交数据详情 |
| `GET /v2/oauth2/authKey` | OAuth2 鉴权 Key 获取 |
| `POST /v3/contracts/paper-file-upload` | 纸质文件上传 |
| `GET /v3/ledger/image-download-urls` | 台账图片下载链接 |

---

## PRD 引用规范

涉及接口可用性限制时，在 PRD §9 或接口说明处标注：

```markdown
> **版本权限约束**：本接口仅限 **[专业版 / 高级版]** 及以上客户调用。
> 版本层级详见：context/product-editions.md
```
