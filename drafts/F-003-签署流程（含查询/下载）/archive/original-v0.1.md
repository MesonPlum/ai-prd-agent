## 三、名词解释（相关部分）

| 名称 | 解释 |
|------|------|
| 签署流程 | 当平台对合同文件发起签署时，会生成一个流程ID-flowId，这个flowId标识当时发起的这笔签署任务的全阶段流程即签署流程。 |

## 六、功能点 — 3. 合同签署业务

### 3.1 创建签署流程

**① 通过文件创建签署流程**

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| files | Array | 是 | 签署文件 list |
| signers | Array | 是 | 签署方 list |
| signflowConfig | Object | 否 | 签署流程全局配置 |

files 属性：

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| fileId | String | 是 | 文件ID |
| fileName | String | 是 | 文件名称 |
| fileType | String | 是 | 文件类型 pdf |

signers 属性：

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| signerType | Integer | 是 | 签署方类型：0-个人，1-机构（法定代表人章由e签宝在内部自动处理） |
| psnAccount | String | 否 | 个人账号，手机号或邮箱 |
| psnId | String | 否 | 个人用户ID |
| orgId | String | 否 | 机构ID |
| orgName | String | 否 | 机构名称 |
| noticeDeveloper | Object | 否 | 通知开发者 |
| signfields | Array | 是 | 签署区列表 |

signfields 属性：

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| fileId | String | 是 | 签署区所在文件ID |
| normalSignFieldConfig | Object | 否 | 普通签署区配置 |
| signOrder | Integer | 否 | 签署顺序 |

signflowConfig 属性：

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| signflowTitle | String | 否 | 合同名称 |
| autoStart | Boolean | 否 | 自动开启 |
| autoFinish | Boolean | 否 | 自动完结 |
| noticeType | String | 否 | 通知方式 |
| redirectUrl | String | 否 | 回跳地址 |
| signValidity | Integer | 否 | 签署截止日期 |
| signValidity | Integer | 否 | 签署流程截止时间 |

**② 通过流程模板创建签署流程（二期）**

通过流程模板signTemplateId创建签署流程

### 3.2 准备待签文件

**① 上传文件**

返回文件上传地址（PUT方法直传）

**② 回调：文件上传成功（待定）**

在文件上传成功后，回调通知开发者

**③ 查询PDF文件详情**

查询文件上传是否成功，并获取文件详情

**④ 回调：文件已损坏/文件有打开密码**

上传的文件无法处理时，回调通知开发者

**⑤ 获取关键字坐标**

通过关键字检索合同文件中关键字出现的坐标

**⑥ 获取《设置填写控件》页面链接（待定）**

获取e签宝的控件填写页面链接

**⑦ 添加控件（待定）**

往合同文件添加一个控件

**⑧ 删除控件（待定）**

删除合同中的某个控件

**⑨ 填充控件生成待签文件**

通过填充模板中的控件批量生成待签文件

### 3.3 修改签署流程配置

**① 追加签署区**

往合同流程中追加一个签署方的签署区

**② 删除签署区**

删除合同流程中的签署区

**③ 修改企业签署经办人（待定）**

修改流程中的企业签署经办人，替换原流程中的某个经办人

**④ 追加待签文件**

往合同流程中追加一个待签文件

**⑤ 删除待签文件**

删除合同流程中的待签文件

**⑥ 追加附件**

往合同流程中追加一个附件

**⑦ 删除附件**

删除合同流程中的附件

**⑧ 追加抄送方（二期）**

往合同流程中追加一个抄送方

**⑨ 删除抄送方（二期）**

删除合同流程中的抄送方

### 3.4 流程状态操作

**① 撤销签署流程**

撤销合同签署流程（合同流程所有签署人的签署链接失效）

**② 开启签署流程**

开启草稿状态下的合同签署流程

**③ 结束签署流程**

结束合同签署流程（合同流程所有签署人的签署链接失效）

**④ 催签**

向流程中签署人发送催签通知

**⑤ 签署流程延期**

延长合同签署流程的截止时间

### 3.5 查询

**① 查询签署流程列表**

查询由当前应用（appId）发起的签署流程列表

**② 查询签署流程详情**

查询签署流程的详情信息

**③ 获取签署链接**

根据签署人账号，获取该签署人的签署链接

### 3.6 回调

**① 签署人申请修改身份信息（待定）**

签署人在签署过程中申请修改身份信息时，通知开发者

**② 经办人主动转交签署任务**

经办人主动转交签署任务时，通知开发者

**③ 填写人已填写（待定）**

流程中的填写人完成填写时，通知开发者

**④ 签署人已读**

签署人打开签署链接，通知开发者

**⑤ 签署人完成签署**

签署人完成签署，通知开发者

**⑥ 签署流程即将到期提醒**

签署流程临近截止时间，通知开发者

**⑦ 签署流程结束**

签署流程结束，通知开发者
